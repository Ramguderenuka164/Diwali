Light up your data skills with the
Database Management System (DBMS)

FESTIVAL OF DATA
📜
CORE FUNCTION 1

DDL: Data Definition Language

Defines the database structure, schema and constraints.

CREATE · ALTER · DROP
✨
CORE FUNCTION 2

DML: Data Manipulation Language

Inserts, updates, deletes and retrieves data.

INSERT · UPDATE · DELETE · SELECT
🔐
CORE FUNCTION 3

DCL and TCL

Manage user permissions, security and transaction consistency (ACID properties).

GRANT · REVOKE · COMMIT · ROLLBACK
⚙️
CORE FUNCTION 4

System Services

Automated backups, recovery, concurrency control and multi-user access.

🗂️
TYPE 1

Relational DBMS (RDBMS)

Structured tables with rows, columns, primary and foreign keys, queried via SQL.

MySQL · PostgreSQL · Oracle · SQL Server
🎆
TYPE 2

NoSQL DBMS

Handles unstructured or semi-structured data for rapid scaling: key-value, document, graph and wide-column.

MongoDB · Cassandra · Redis
☁️
TYPE 3

Specialized DBMS

Object-oriented, hierarchical, network and cloud-based databases.

Amazon RDS · Snowflake
